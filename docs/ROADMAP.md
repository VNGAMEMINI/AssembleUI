# AssembleUI Roadmap

This roadmap tracks areas that need review and improvement.
Items are proposals until their scope and acceptance criteria are defined.

## 1. Component and Pattern Coverage

- Review missing or incomplete components and patterns.
- Prioritize Autocomplete, Breadcrumb, Calendar, Callout, DataGrid,
  DescriptionList, DatePicker, Divider, Field, Form, Rating, SkipLink,
  Stat, and Tooltip where work is still needed.

## 2. Interface Quality

- Review visual consistency across components and patterns.
- Check responsive behavior, accessibility, and interaction states.

## 3. Developer Experience

- Review component APIs and usage examples.
- Improve reuse and customization without introducing style or data conflicts.
- Keep public imports and documentation consistent.

## 4. Completion Criteria

- Tests cover expected behavior and important edge cases.
- TypeScript checks and production builds pass.
- Sass styles and design tokens follow the project's architecture.
- Public APIs and examples are documented.
